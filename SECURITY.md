# Security policy

## Supported version

Security fixes are provided for the latest release on the `main` branch. Pre-release snapshots and historical revisions are unsupported.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email `contact@siweiyu.com` with a concise description, affected version or commit, reproduction steps, and impact. You should receive an acknowledgment within seven days.

Do not include credentials, private imagery, model-access tokens, or other sensitive data in the initial report. We will coordinate a secure transfer method if supporting material is needed.
